# Architecture decision records

Significant decisions, one file each, numbered in order. The initial decisions are summarised
in [PLAN.md §11](../PLAN.md#11-decision-log); new ones are recorded here.

| ADR                                           | Decision                      | Status   |
| --------------------------------------------- | ----------------------------- | -------- |
| [0001](0001-record-architecture-decisions.md) | Record architecture decisions | Accepted |
| [0002](0002-http-api-conventions.md)          | HTTP API conventions          | Accepted |

## Template

```markdown
# NNNN. Title

- Status: proposed | accepted | superseded by NNNN
- Date: YYYY-MM-DD

## Context

What forces the decision: the problem, constraints and options considered.

## Decision

What we chose.

## Consequences

What becomes easier or harder, and what we will need to revisit.
```
